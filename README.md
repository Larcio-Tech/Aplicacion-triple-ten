# Aplicación TripleTen

Aplicación web desarrollada con Python y Streamlit como parte de los ejercicios de TripleTen.

La aplicación simula lanzamientos de una moneda y muestra cómo evoluciona la media de los resultados a medida que aumenta el número de intentos.

## Tecnologías utilizadas

- Python
- Streamlit
- Pandas
- SciPy

## Funcionalidades

- Seleccionar el número de lanzamientos.
- Simular lanzamientos de una moneda.
- Visualizar la evolución de la media mediante un gráfico.
- Guardar y mostrar los resultados de los experimentos realizados.
